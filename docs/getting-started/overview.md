# Getting started

The smallest supported local path runs the operations Console with the deterministic AI provider. It requires the .NET SDK, but no Azure subscription, remote API key, Docker installation, or live model.

1. Check the [prerequisites](prerequisites.md).
2. Follow the [local installation](local-installation.md).
3. Verify the [first start](first-start.md).
4. Review the available [configuration](configuration.md).

Agentstration also has a standalone Workplace host backed by a separate Work API. Start those two processes when you want the end-user experience rather than the operations Console.
