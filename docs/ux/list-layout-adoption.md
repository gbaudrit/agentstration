# List-layout adoption on codex/ux-corrections

## Bounded ownership

The continuing scope is the remaining top-level list adapters recorded below, handled one screen at a time. Each next screen is announced before editing. Completed earlier screens retain their evidence and commits; this ledger is a progress record, not an instruction to stop after a fixed number of screens. Other accessible work concerns resource details, wizards and CI. This checkout is separate from those workspaces. Shared components, protected pilots, details and creation forms remain outside this migration. Embedded collections keep their applicable contracts and are not rewritten as page templates.


Each screen is completed, checked, committed and published before the next starts. The reusable scenario #1242 remains blocked pending explicit UX validation and merge. Ad hoc smoke checks do not implement that scenario. Existing parent #1241 and child #1242 track this composition work; no additional duplicate scenario issue is created.
