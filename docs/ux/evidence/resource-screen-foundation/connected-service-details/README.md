# Connected Service persisted screen

The persisted `/connected-services/{name}` route uses ConsoleResourceDetailsTemplate. Overview presents authorized availability/revision/dependent-count indicators before saved Identity (including labels), wrapping Configuration and diagnostics. Definition starts with Identity, Configuration, and the separate descendant-use policy. Discovery and Dependents retain their domain behavior; independently authorized Access and final canonical, read-only declaration YAML use the adapter. A dependent projection with no qualified identity does not acquire a fictional namespace/owner.

The retained ConnectedServiceEditor shares the layout's exact ResourceSectionState and presentation dictionary and declares real root fields. Creation remains the previously verified CreationWizard. Properties-only API capabilities retain read-only labels and immutable saved namespace/type. Commands and payloads, bindings, pinned type UID/version/schema digest, permissions, confirmations and ETags remain family-owned. There is no new loader or universal resource schema.

Refresh retains the EditContext, invalid parser buffers, contextual creator and original ETag; it buffers a newer snapshot for explicit Discard. Input during a pending refresh remains editable, while save is blocked. Lost access/deletion/replaced UID clears cached private content; stale/disposed completions cannot restore it. Independent activation reconciles its new ETag without saving other definition fields. Access remains independent of managed-definition read-only state.

A real browser probe exposed native HTML constraint validation blocking submission from Overview when an invalid numeric control lived in a hidden Configuration section. ResourceDefinitionForm now uses novalidate so its existing Blazor annotations, parser/schema stores and section-routing/focus can execute. No model/schema validation is removed. The protected Agent's source, styles and translations remain untouched and its maintained desktop/mobile journey is rerun for this shared change.

Concurrency feedback is localized in English/French and preserves the conflicting draft and its original ETag without showing backend detail. The final native probes pass on English/dark desktop and French/light true touch mobile: hidden invalid numeric controls route/focus from Overview; raw JSON/context/old ETag survive navigation and a real concurrent API write plus Refresh; stale save displays the localized conflict without overwriting the server; explicit Discard adopts the newer snapshot and a subsequent Save preserves its configuration. Header activation cancellation retains the independent draft; descendant-use, discovery, dependents and exact-UID Access are inspected, with Escape/focus return and no horizontal document overflow. The 26 PNGs below are unmodified screenshots of the running application. All 47 targeted component cases pass, TypeScript passes and all three actual Release hosts build with zero warnings/errors. Maintained Storage/Connected Service and protected Agent desktop/mobile journeys pass in campaign 02 against the same shared form; the final native campaign 04 additionally verifies localized concurrency feedback. Exact source/host hashes and chronology are in [verification.json](verification.json). The initial native probe is retained outside the repository as red-before-fix evidence. A subsequent probe waited for browser HTTP traffic for a server-side Blazor command; that observation was corrected to assert the visible localized concurrency feedback and unchanged server resource, without relaxing application assertions or extending timeouts; it is not presented as successful verification. CI failures are outside this work at the maintainer's explicit request. New reusable transverse scenario #1236 remains deferred until maintainer UX validation and implementation merge; existing journeys are maintained.
