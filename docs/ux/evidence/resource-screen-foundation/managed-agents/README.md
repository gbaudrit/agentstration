# Pack-managed Agent: common immutable-resource inspection

`/namespaces/{AgentNamespace}/agents/{Name}` keeps its separate Pack-managed resource contract. Non-managed Agents still redirect to the protected ordinary Agent editor with exact namespace/owner/context and safe return/fragment mapping. This migration changes neither AgentEditor, its model/styles/translations nor any shared presentation component.

The persisted managed Agent now uses ConsoleResourceDetailsTemplate, the same ResourceSectionState/presentation dictionary and one retained, locked ResourceDefinitionForm with real root Fields. Overview uses the common adaptive MetricCard region before saved Identity/labels and complete saved Configuration. Definition starts with common Identity then Configuration, followed by original Pack definition, Model and Runtime. Independent Access precedes final YAML. Installation provenance enriches Identity through AdditionalPanels. No creation, definition save, activation or publication capability is invented on this immutable route; ordinary creation keeps the protected Agent wizard.

The original Pack declaration is a specialized, read-only historical/authoring snapshot. Its existing graphical fields retain logical binding expressions and annotations; they are not substituted for the actual saved Identity/Configuration. Its labels inside that snapshot retain their source meaning, while live saved resource labels appear inside common Identity. PackAgentDefinitionForm is a div-based specialized reader inside the single common form, not a nested EditForm. YAML preserves the exact authorized original Pack source. Missing/denied/mismatched provenance uses the saved resolved Agent manifest with explicit localized fallback help, rather than presenting it as the unavailable original.

Pack provenance must match actual publisher/name, namespace, owner and recorded version before it can supply source/bindings. Wrong-owner homonyms and incomplete owner responses do not become provenance. No owner/namespace is guessed and no query per row is introduced. Runtime commands retain exact namespace/owner/generation and resources/write authorization independently from definition immutability; they sit in header/ReadOnlyActions outside locked fieldsets. Readiness inspection has independent failure handling: unavailable observation is neutral Unknown and cannot deny the saved Agent inspection.

Shared typed loading/refresh/error/retry replaces custom state branches. Recoverable main/provenance failures retain inspection, original source/form context and independent policy drafts. Main-resource 401/403/404, replaced UID/address/owner and superseded/disposed replies clear or cannot replace private content. Losing only Pack-source access removes its private declaration while retaining authorized Agent metadata and its policy draft. The common adapter owns the single combined leave guard. Family commands, original schema/binding readers, confirmations, endpoints and business counters are unchanged; this route has no definition-write ETag to invent.
