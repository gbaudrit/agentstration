# Flow orchestration — retained delegated definition editor

The delegated editor uses ResourceDefinitionForm with the owning Flow layout's exact ResourceSectionState and presentation dictionary, root Fields, localized annotations and first-error navigation/focus. ResourceIdentityEditor places immutable technical identity and read-only metadata labels in Identity; Configuration retains the specialized orchestration participant/manager and strategy controls. Standalone aliases still lead to the same exact Flow coordinates; no second frame or creation wizard is fabricated for a persisted delegated editor.

Exact pinned/relative references, business validation, ETags and save-before-publication semantics are preserved. Activation acknowledgement retains the same EditContext, invalid controls, metadata and independently typed publication version. Explicit snapshot/discard adoption is caller-owned; ordinary unchanged refresh does not reset the editor. Permission loss retains a guarded read-only draft, and stale context/identity callbacks cannot replace it. The native check performs real save, independent activation and publication and verifies the unchanged scoped participant references.

The current coordinated checks pass: 96 Console Flow cases and 104 designer/store cases, within 397 targeted cases overall. After the final local caption/Entry preview changes, 121 affected cases were rerun successfully, and the three Release hosts were rebuilt without warnings/errors. Native English/dark desktop and French/light true-touch checks pass for this screen, with strict bounds and retained draft assertions. The maintained Flow and protected Agent journeys pass; the protected Agent source, styles and translations remain unchanged.

These PNGs are unmodified captures of the running application. Exact source, host, report and screenshot hashes are recorded in verification.json. New reusable #1236 coverage remains deferred until explicit UX validation and merge; maintained journeys continue to be checked. No CI investigation or full solution lanes were performed, as requested.

Observed limits:

- This delegated preparation is paired with the owning FlowDetails migration in the working tree; each screen has a separate commit.
- Metadata tags stay read-only because this existing definition update command does not write them.
- The specialized shared topology retains its existing generated English description and raw technical statuses; the standard controls and the new save caption are localized.
