# Schema Actions and Preview smoke

Source hashes in the observations identify the tested product files, including shared native fragment synchronization and summary layout. Synthetic disposable local data only; no model invocation or value mutation during inspection. The recorded four variants cover desktop 1440 × 1000 / mobile 390 × 844, English/light and French/dark on desktop, English/dark and French/light on mobile.

All four cases passed: shared saved identity/configuration, independently foldable sections, hidden view selector, bounded document and panel widths, reachable close, Open/Edit followed by browser Back, reload/direct links, Escape, explicit close and reopening the same native fragment after closing. No unhandled browser errors occurred. [Machine-readable observations](observations.json) record each screenshot and its actual checks. Component tests separately prove exact scoped reads, rejection, cancellation and no unopened-row detail reads.
