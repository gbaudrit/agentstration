This is the expanded closure inventory. An implementation is recorded separately from its final verification; source adoption alone is not UX acceptance. The first five-screen evidence remains wave 1 only.

The final campaign must reconcile any additional collection discovered in source or browser navigation.

- Console conversations retain the existing 50-result bound. Runs, workers, assignments, events, acquisitions, projections, snapshots and details retain their existing family snapshot/history/live-buffer limits. Rendering and view switching add no data requests.
