# Interactions

An Interaction is a durable Workplace conversation. It retains functional messages, pending actions, and links to successive executions while remaining open after a Task completes.

An Interaction can produce an immediate response or create asynchronous work. Follow-up messages start new execution without reopening the previous FlowRun. This makes Interaction different from both a technical Runtime Run and a [WorkTask](work-tasks.md).

See [ADR-0022](../decisions/0022-interaction-durable-conversation-flow-continuation.md).
